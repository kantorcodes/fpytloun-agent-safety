# Contributing to Awesome Agent Safety

Thank you for helping build the definitive resource for AI agent safety tooling.

## Guidelines

### Adding a New Resource

Please ensure your pull request meets the following criteria:

- **Relevant**: The resource must be directly related to AI agent safety, authorization, guardrails, auditing, monitoring, red teaming, or compliance.
- **Quality**: The project should be actively maintained, well-documented, and useful to the community.
- **Description**: Provide a concise, objective description. Avoid marketing language.
- **Formatting**: Follow the existing format: `- [Name](URL) - Description. License.`
- **Alphabetical**: Add new entries in alphabetical order within their section.
- **License**: Include the license for open-source projects. Mark commercial products with `(commercial)`.

### What We Accept

- Open-source tools and libraries for agent safety
- Commercial products that are widely used in the space
- Research papers published on arXiv or in peer-reviewed venues
- Standards and frameworks from recognized organizations (OWASP, NIST, ISO, etc.)
- High-quality blog posts and articles with original analysis

### What We Don't Accept

- Self-promotional content without real substance
- Projects that are abandoned or unmaintained (no commits in 12+ months)
- Duplicate entries or tools that are trivially similar to existing entries
- Resources behind paywalls (unless they are industry standards like ISO)
- AI-generated listicles or low-effort content

### Suggesting a New Category

If you think a new category is needed, open an issue first to discuss it. Categories should:

- Contain at least 3 entries
- Be distinct from existing categories
- Cover an important aspect of agent safety

### How to Submit

1. Fork this repository
2. Create a new branch: `git checkout -b add-tool-name`
3. Add your resource following the format above
4. Commit with a clear message: `Add ToolName to Content Safety section`
5. Open a pull request with a brief explanation of why the resource belongs on this list

### Updating Existing Entries

If a project has been renamed, moved, or its description is outdated, please submit a PR with the correction. Include a link to the source of the updated information.

### Reporting Issues

If you find a broken link, an entry that no longer meets the quality bar, or a factual error, please open an issue.

## Code of Conduct

Be respectful, constructive, and objective. This list aims to be a fair and comprehensive resource for the entire AI safety community.
